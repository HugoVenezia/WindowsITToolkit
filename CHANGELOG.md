\## \[v1.2] - 2026-09-14



\### Added

\- Operation progress bar

\- Diagnostic completion percentage

\- Current diagnostic stage information

\- Quick Diagnostic workflow

\- HTTPS TCP/443 connectivity check

\- Resource-specific recommendations

\- Tool Scope / About information

\- Scope and Limitations section in PDF reports

\- Smart Network Diagnostics

\- Network connectivity analysis

\- ICMP failure interpretation

\- PDF IT Health Report
