\# Windows IT Toolkit



Windows IT Toolkit is a Windows desktop diagnostic utility designed for IT technicians and system administrators.



It provides common system and network diagnostic tools through a simple graphical interface and can generate professional PDF health reports.



\## Features



\- System Information

\- Network Information

\- Ping Test

\- DNS Test

\- TCP Port Test

\- PC Health Check

\- Smart Network Diagnostics

\- PDF IT Health Report

\- Customer / Company information

\- Technician information

\- Automatic diagnostic recommendations



\## PC Health Check



Windows IT Toolkit can check:



\- CPU usage

\- RAM usage

\- Disk usage

\- Available memory

\- Available disk space



The application automatically classifies results as:



\- OK

\- WARNING

\- CRITICAL



\## Network Diagnostics



The toolkit can test:



\- Default Gateway

\- Internet connectivity

\- DNS resolution

\- TCP port connectivity



Smart Network Diagnostics provides automatic recommendations based on the test results.



\## PDF Reports



Windows IT Toolkit can generate professional IT Health Reports containing:



\- Customer / Company

\- Technician

\- Report ID

\- Computer information

\- System health

\- Network health

\- Executive summary

\- Recommendations



\## Requirements



For running from source:



\- Windows 10 / Windows 11

\- Python 3

\- psutil

\- ReportLab
