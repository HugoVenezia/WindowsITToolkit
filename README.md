## Download

The latest Windows executable is available from the GitHub Releases section.

Download the current release and run `WindowsITToolkit.exe`.

> Windows may display a SmartScreen warning because the application is currently unsigned. Always download the executable from the official project repository.

## Feedback

Windows IT Toolkit is currently being tested with real users before the next major development cycle.

Your feedback is valuable and will directly influence future versions.

If you experience a problem, please open a **Bug Report** in the GitHub Issues section.

If you have an idea for a new feature or improvement, please open a **Feature Request**.

When reporting problems, please avoid sharing passwords, credentials, private keys, or other sensitive information.
